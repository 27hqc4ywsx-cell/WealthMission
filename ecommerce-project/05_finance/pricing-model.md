# Preismodell

**Stand:** 2026-07-11 · Preis ist Testvariable (H1/Angebotsänderung in validation-plan.md), kein Rabatt-Hebel (Stresstest: unter ~15 € kippt die Ziel-CAC-Logik).

## Preisarchitektur

| Angebot | Preis | Logik |
|---|---|---|
| 52W-Challenge „Lite“ | 0 € (E-Mail, DOI) | Funnel-Eintritt; enthält bewusst NUR Modul 3 light |
| **Money OS Vollversion** | **24,99 € inkl. USt** | Anker zwischen Template-Segment (~10 €, Q-04) und Jahres-Abo-Kosten (36–120 €); Rechtfertigung über Interaktivität + 4 Module |
| Preistest-Variante | 19,99 € | nur falls H1 scheitert; niemals als „Streichpreis von 24,99 €“ darstellen (PAngV/Referenzpreis-Regel) |
| Folgeprodukte (Phase 16) | 9–19 € | Module (Schulden, Paare) als Add-ons |

## Regeln

1. Keine Fake-Rabatte, keine Countdown-Timer, keine erfundenen „Vorher“-Preise (Auftragsregel + PAngV)
2. Echte Aktionen (z. B. Launch-Wochen-Preis) sind zulässig, wenn Referenzpreis-Regeln eingehalten werden → vor erster Aktion anwaltlich prüfen (30-Tage-Bestpreis-Regel)
3. Preisänderungen nur mit Experiment-Eintrag (Hypothese, Dauer, KPI) im Experiment-Backlog
